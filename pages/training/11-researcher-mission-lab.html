The Researcher Mission

The payoff. The diligence brief you commissioned in Module 1 has been running while you worked — now you collect it, review it like the professional whose name goes on it, and turn it into the one-page memo the deal team would actually receive. Everything here runs on the synthetic Project Lighthouse data room — fake and safe for Copilot; nothing real goes into a prompt.

The Researcher Agent · ~10 min in-room · memo & debrief continue as take-home
01 — Collect the report

Your report came home

You briefed Researcher on the Lighthouse mission back in Module 1 and left it working — the commission-early move in action. Time to see what came back.

01
Open your run
In the Microsoft 365 Copilot app, go to Agents → Researcher and open your Project Lighthouse session. The report should be waiting — a structured document with headings and citations, not a chat bubble.
02
Still running? Pair up
Complex runs can take up to 45 minutes, and start times varied around the room. If yours isn't done, pair with a neighbor whose report has landed and review theirs together — the facilitator also has a spare completed run on the projector machine.
03
First skim: shape, not substance
Thirty seconds, structure only: did it produce headed sections, does it stay near the six-page cap, and do citations appear throughout? You're checking that the deliverable spec in the brief was honored before you read a single claim.
🗄️
Checkpoint: this report isn't a record yet

Same rule from Module 1: Researcher session content is not e-discoverable by default, unlike regular Copilot chat history. Right now this report only exists inside the agent session. If it's about to become real diligence work product — which it is, in about five minutes — it needs to land in a governed file, not stay parked here. The memo step below is where that happens; this is the reminder to actually do it.

02 — The review pass

Review it like you'd sign it

The brief asked four numbered questions. This pass holds the report to them — the same structured skepticism you'd apply to a junior analyst's first diligence draft. Work through all four checks; note what you find, because it feeds the memo.

01
Four questions, four answers?
The brief asked about revenue quality, carrier concentration, market conditions vs the earn-out, and pre-close questions. Find where each is answered. An unanswered question is a finding, not a failure — it goes in the memo.
02
Spot-check three citations
Pick three cited claims — at least one work-sourced, one web-sourced. Open each source: does it actually say what the report says it does? A citation that exists is not the same as a citation that supports.
03
Separate work from web
Mark which claims trace to the data-room files and which to public web sources. The split matters downstream: data-room claims are diligence findings; web claims are market context that can age.
04
Note what it declined or missed
Did it flag anything it couldn't assess — and did it catch what you'd catch? (One tell from Lesson 1: charts saved as images in input files are invisible to Researcher.) Gaps you spot are exactly what your follow-up in the same session should chase.
03 — Turn it into the deliverable

From report to memo

A Researcher report is an input, not an output. The deal team gets one page. Open Word, paste in the report (or the sections that survived your review), and hand Copilot the drafting job — then save the result where governance can see it.

In Word → Copilot, with the report content in the document 
Using the Researcher report content in this document, draft a one-page diligence memo for the deal team on the Project Lighthouse acquisition. Format: five headed sections — (1) Revenue quality, (2) Carrier concentration risk, (3) Market conditions and the earn-out, (4) Questions before close, (5) Recommendation. Sections 1–4 summarize the report's answer to the matching question in two or three sentences each, keeping the report's citations; where my review found a claim unsupported or a question unanswered, say so plainly rather than papering over it. Section 5 is one short paragraph. Neutral diligence language throughout — findings and open questions, no deal advocacy, no adjectives.
🔎
Before it leaves your desk — did the citations survive the rewrite?

Copilot just compressed a six-page cited report into five short sections. Compression is where citations quietly disappear. Check each section against the report: is every claim still traceable to a source, or did a caveat get smoothed into a flat statement along the way? If a sentence reads more confident than its source supports, that's a rewrite, not a review pass.

🗄️
Save the memo to OneDrive — that's the record

Remember the nuance from Lesson 2: agent session content is not e-discoverable by default. Your Word memo in OneDrive is the governed artifact — retention, eDiscovery, and sharing controls all apply to it, none of them to the session it came from. Saving the file is the compliance step, not an afterthought.

04 — Debrief

Researcher on your real desk

You've now run the full loop: brief, clarify, wait, review, deliver. The last move makes it stick — before leaving this module, write one real mission you'll commission this month. You'll carry it into Module 4's Make It Stick, where it becomes a commitment, not a note.

Name the mission

Pick from your actual queue — a deal file, a quarterly estimate backdrop, a disclosure benchmark, an audit-committee prep pack. If Lesson 3 named your beat, steal its mission.

Draft the brief line

One sentence with all four elements: objective, scope & sources, deliverable spec, audience. If you can't write the sentence, the mission isn't ready to commission yet — which is also worth knowing.

Put it on the calendar

Decide when it runs — ideally a week before you need the output, off the critical path. One well-briefed run from your monthly 25 is the whole habit; this is the first one.
