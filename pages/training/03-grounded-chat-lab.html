The Chat Sprint Lab

Ten minutes, laptops open. You'll run three grounded prompts against the session's synthetic finance files, judge the output like a reviewer — and commission your first Researcher run so its report is waiting for you in Module 3. Everything here uses fake data shaped like ours; nothing real goes into a prompt today.

Foundations & Copilot Chat · ~10 min in-room
01 — Setup check

Files in place, source named

You did this in pre-work — take thirty seconds to confirm it stuck. Copilot can only ground in files it can reach, and in the source you actually name in the prompt.

01
Lab files in OneDrive
Confirm the Copilot Workshop folder in your OneDrive contains profit-center-pnl.csv and the data-room folder. Missing? Re-download from the resource library.
02
Open Copilot, name the source
Open Microsoft 365 Copilot and start a new chat. If Work IQ is available, keep it enabled for this lab — you're working from Microsoft 365 files. Then reference the lab file directly using /profit-center-pnl.csv so Copilot grounds the answer in the source you intend, not whatever it finds on its own.
03
Test the reference
Type "/" and start typing profit-center-pnl. If the file appears, you're grounded and ready. If it doesn't, pause and troubleshoot access: confirm the file is in OneDrive, you have permission, the file has finished indexing, and the prompt names it clearly — flag a facilitator if it's still missing.
02 — The sprint

Three prompts, four elements each

Run these in order in one chat. Each one exercises the Goal–Context–Expectations–Source framework on a different finance move: find, explain, draft. Watch how the thread builds — prompt three leans on what came before.

Prompt 1 — find (reference the file with "/") 
Using /profit-center-pnl.csv as the source, identify the five largest unfavorable variances vs budget in June 2026 across all profit centers and accounts. Ground your analysis exclusively in this file. Give me a table showing profit center, account, budget, actual, and variance dollars, sorted largest first. Flag any profit center appearing more than once.
Prompt 2 — explain (iterate on the thread) 
Using the findings from this chat and the data contained in /profit-center-pnl.csv, evaluate the largest variance from January through June. Determine whether it appears to be a one-time event or an ongoing trend. Answer in three sentences and identify the months supporting your conclusion.
Prompt 3 — draft (audience + format) 
Using the analysis from this conversation and /profit-center-pnl.csv, draft the June variance commentary paragraph for the segment controller. Use only information supported by the data already reviewed. Format as: one short lead sentence summarizing the month overall, then one sentence per top variance naming the profit center, the driver, and whether it recurs. Use plain, factual close-package language. Do not speculate.
🔎
Before you read the answer — where did it come from?

After each prompt, check Copilot's citation before you trust the text: does it say profit-center-pnl.csv, and only that file? If a source card cites something else — or nothing — that's your cue to tighten the prompt and rerun, not to keep going. Once you've run Prompt 3, compare your paragraph's shape against flash-comments.csv in the lab-data folder — a real flash-commentary export, one lead sentence plus a driver per line, is what "close-package language" looks like in practice.

03 — Commission your agent

Kick off Researcher now

Researcher runs take 10–45 minutes on complex briefs — so advanced users commission the run early and keep working. Start this now and its report will be ready when we reach Module 3. It will ask clarifying questions first: answer them, that's the point.

In the Copilot app → Agents → Researcher (or @Researcher in chat) 
I'm on the finance team at a large US insurance brokerage, evaluating an acquisition target. Using the Project Lighthouse files in my OneDrive Copilot Workshop folder (the CIM extract, 3-year financials, carrier contract summary, and earn-out term sheet) AND public web sources on the Florida coastal property insurance market, produce a diligence brief that covers: (1) the quality of the target's revenue growth, separating contingent commissions from core commissions; (2) carrier concentration risk and which single relationship most threatens contingent income; (3) how current Florida coastal property market conditions could affect the proposed earn-out; (4) the five questions finance should ask before close. Structured report with headings and citations; keep it under six pages.
⏱️
Answer the clarifying questions, then walk away

When Researcher asks about scope, tell it: work files and web, US market focus, finance audience. Then leave it running and return to the session — checking on it is Module 3's opening move. Remember the budget: Researcher and Analyst share 25 queries a month, so one well-briefed run beats three vague ones.

04 — The reviewer's bar

Judge it like you'd sign it

Copilot drafts; you own. Before the sprint counts as done, hold prompt 3's output to the same bar you'd hold a junior analyst's draft.

Numbers trace

Every figure in the paragraph should trace to the CSV. Spot-check two against the file. If Copilot rounded or blended, tighten the prompt and rerun.

Drivers are claims

"Driver" language is an assertion — is it supported by the data, or inferred? Anything inferred gets rewritten as a question for the profit-center lead, not stated as fact.

Tone survives review

Would the segment controller forward this untouched? If you'd edit the tone, tell Copilot what to change — that instruction belongs in your reusable prompt.
