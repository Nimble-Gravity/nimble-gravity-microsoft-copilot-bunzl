The Close-Package Lab

Seven minutes, laptops open: build a mini close package by chaining the apps — a variance table in Excel, the commentary paragraph in Word, and (if you're fast) a one-slide summary. Everything runs on the session's synthetic P&L; the data is fake and safe to use with Copilot. Then take the full circuit home: the Variance Vault is waiting.

Copilot in the Apps · ~7 min in-room + take-home
01 — The task

Excel → Word, one chain

You opened profit-center-pnl.csv in desktop Excel during pre-work — open it again now. The circuit: ask Copilot in Excel for the June variance table, then switch to Word and draft the commentary that references it. Synthetic data, real workflow.

01
Excel — the variance table
With profit-center-pnl.csv open, save it as profit-center-pnl.xlsx into your OneDrive Copilot Workshop folder (Copilot works on saved workbooks, not raw CSVs), then run prompt 1 in the Copilot pane. If Copilot proposes a plan first, read it before approving.
02
Word — the commentary
New Word document, run prompt 2. Reference the workbook you just built (type "/" and pick it, or attach it) so the paragraph is grounded in your actual table — not Copilot's memory of it.
03
Stretch — the one-slider
Finished early? Open PowerPoint and use Narrative Builder: "one slide summarizing the June budget-vs-actual results by profit center," referencing the same workbook. Outline first, then let it build.
Prompt 1 — Copilot in Excel, with profit-center-pnl.csv open 
Build a June 2026 budget-vs-actual variance table by profit center on a new sheet. Columns: profit center, June budget, June actual, $ variance, % variance. Sort by $ variance, most unfavorable first, and highlight any profit center where the unfavorable variance exceeds 10% of budget. Keep the original data unchanged.
Prompt 2 — Copilot in Word, referencing your workbook with "/" 
Using the June variance table in /profit-center-pnl.xlsx, draft the June close-commentary paragraph for the segment controller. Cover the three most unfavorable variances: one lead sentence on the month overall, then one sentence per variance naming the profit center, the dollar and percent variance, and whether the same center was unfavorable in prior months. Plain, factual close-package language — neutral tone, no speculation about causes.
02 — The verify pass

Before it counts, check it

The lab isn't done when Copilot finishes — it's done when you've reviewed it. Two minutes, three checks: the same pass this deliverable would get before a controller saw it.

Show Changes

See what Copilot actually touched

In Excel, open Review → Show Changes and find the Copilot-attributed edits. Confirm it built the new sheet and left the source data alone — the attribution trail is the audit answer for agentic edits, so make reading it a reflex.

If anything in the original data changed, undo, tighten the prompt ("keep the original data unchanged"), rerun.
Spot-check

Trace two numbers to the CSV

Pick two variances from the table and tie them back to the raw rows in profit-center-pnl.csv — budget, actual, math. Then reread the Word paragraph: every figure it quotes should match your table exactly, and no "driver" should be stated that the data doesn't support.

Tone check: would the segment controller forward this untouched? If not, tell Copilot what to change — and keep that instruction for next month.
03 — Take-home extension

The Variance Vault

The in-room circuit was the warm-up. The Variance Vault is a four-room escape-room challenge on the same synthetic data — each room hands you a finance puzzle only good prompting gets you out of. Run it solo after the session, or make it a team event with the people at your table.

Four rooms, one dataset

Each room poses a challenge on the P&L and commission-statement files — find the anomaly, explain the trend, draft the answer — and each unlock code comes from getting Copilot to the right result.

Solo or squad

Solo is a solid hour of prompting practice; as a team it's a race — same rooms, shared screen, loudest table wins. Either way it's synthetic data, so experiment freely.
